This round is about ferries, lanterns, and a schedule that looks simpler than it is. The notes below are original practice text.

A. Lantern Count

Hang lanterns on a path of n poles. A lantern at pole i lights a radius of r. Count poles that stay dark.

Walk from left to right and keep the furthest pole covered so far. When the next pole is beyond that reach, start a new lantern. Use covered for the current reach, which is only notation, not the full program.

  • Sort the pole positions.
  • Place a lantern only when the sweep falls short.
  • Add the radius to the new reach.
covered = max(covered, position + radius)

The same sweep answers the sample. Poles at 1, 4, and 10 with radius 2 need two lanterns.

function lanterns(poles, radius) {
  let covered = -1;
  let used = 0;
  for (const pole of poles) {
    if (pole > covered) {
      used += 1;
      covered = pole + radius;
    }
  }
  return used;
}

B. Ferry Schedule

Boats leave every w minutes, but a boat is skipped when the dock is busy. Find the earliest boat a traveler can catch after time t.

WindowStatus
0 to wOpen
w to 2wBusy

Jump by groups of windows instead of simulating every minute. The busy pattern repeats, so a direct formula finds the next open slot.

Worked example

For t = 5 and w = 4, the next open departure is 8. The arithmetic sits here until you open this spoiler yourself.

next = ((Math.floor(t / w) + 1) | 1) * w;
function nextFerry(time, width) {
  const windowIndex = Math.floor(time / width) + 1;
  const openIndex = windowIndex + (windowIndex % 2);
  return openIndex * width;
}
